# RAG / GraphRAG 評価方式

状態: 評価設計案。数値目標・実績は案件ごとに決めます。

## 公平な比較

キーワード、ベクトル、ハイブリッド、GraphRAG、必要なら構造化照会を、同じコーパス版、質問、権限、モデル、プロンプト、生成予算で比較します。乱数シード、依存版、索引作成日時、設定を保存し、索引作成費用と質問時費用を別に記録します。

## 評価セット

各質問に質問種別、許可ユーザー、期待回答、正解根拠（ソースID・位置）、回答不能時の正しい挙動、重大度、レビュー者を持たせます。重複、改訂版、否定、日付、数値、複数根拠、曖昧な質問を含めます。最終評価用質問はチューニング用と分離します。合成データはデモ動作の確認に限り、実運用の精度へ一般化しません。

## 指標

- 検索: Recall@k、MRR、nDCG@k、根拠適合率・網羅率
- 回答: 正確性、根拠整合性、出典一致、完全性、適切な棄権率
- 安全: ACL越境、削除情報の再出現、個人情報露出
- 運用: p50/p95遅延、失敗率、再索引時間、更新遅延、費用
- 業務: タスク時間、修正率、信頼度、エスカレーション率

## 判定

自動指標とブラインド人手評価を併用し、不一致は専門家が判定します。平均だけでなく重大な失敗例と信頼区間を報告します。権限外文書、削除済み版、矛盾する最新版、情報不足、古い情報、誤OCR、同名エンティティ、前提誤り、検索結果なしを必ず試験します。
