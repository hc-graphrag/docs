# 情報圧縮とコンテキスト注入のアセスメント

状態: GraphRAG 標準テンプレートを対象業務へ適用するための質問票。案件ごとの技術方式選定には使用しません。

## 利用目的とコンテキスト

- 誰または何がコンテキストを利用するか
- どの判断、調査、表示、処理を支援するか
- 一度に扱える情報量、時間、遅延、費用の上限
- 文章、表、関係図、構造化値、証拠束のどの形式で注入するか
- 情報不足、矛盾、権限外の場合にどのように止めるか

## 情報空間と保持条件

- 対象となる文書、データベース、出来事、実体、関係、制約
- 必ず保持する事実、関係、例外、反証、少数例、来歴
- 捨ててもよい情報と、許容できない歪み
- 版、有効期間、所有者、更新・削除頻度
- 文書、行・列、実体・関係単位の権限
- スキャン、表、図面、手書き、暗黙知の割合

## 圧縮表現

- チャンク、語彙索引、ベクトル、階層要約、グラフ、構造化ビューの役割
- 局所、近傍、集団、全体の解像度
- 原文から表現を作る変換履歴と再現性
- 原文位置へ戻るための識別子
- 抽出・要約の誤りを検出するレビュー方法

## レコード案

| 項目 | 説明 |
|---|---|
| source_id, version_id | 安定したソースIDと版 |
| source_uri, page_or_sheet, span | 原情報の位置 |
| tenant_id, acl | 投影前に適用するアクセス属性 |
| created_at, updated_at, valid_from/to | 変更と有効期間 |
| content_type, language, parser_version | 形式と変換系統 |
| representation_id, parent_id, resolution | 圧縮表現と解像度 |
| entities, relations, claims | グラフ要素と抽出根拠 |
| confidence, provenance | 不確実性と来歴 |
| checksum, deleted_at | 差分検出と削除伝播 |

## 着手ゲート

1. 利用主体と変えたい判断・作業が定義されている。
2. 原情報と所有者を特定できる。
3. 必ず保持する情報と許容損失を定義できる。
4. 出力から原情報、版、位置、変換履歴へ戻れる。
5. 権限、更新、削除を圧縮表現と注入時の双方へ反映できる。
6. GraphRAG テンプレートの適用仮説、調整箇所、失敗条件が書かれている。
7. 運用、監視、評価、撤回の責任者がいる。

未達項目があれば、検索パラメータの調整より先に不足を解消します。成功条件は GraphRAG を採用した事実ではなく、標準テンプレートを適用して利用者の業務判断を改善できたことです。
