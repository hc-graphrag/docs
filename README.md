# GraphRAG docs

このリポジトリは、情報の圧縮とコンテキスト注入という原理に基づく設計資料と、GraphRAG を RAG 導入の標準テンプレートとして提供・改善するための資料を管理します。

あそぴてっくは、ユーザーのビジネス課題を起点に、コスト、品質、導入期間、再利用性を総合し、GraphRAG を現状の最尤解と判断しています。この判断を案件ごとに白紙へ戻さず、GraphRAG テンプレートを標準提案として利用します。

案件単位で行うのは技術方式の選定ではなく、GraphRAG テンプレートを対象業務へどう適用するかの設計です。技術者側でテンプレートのコストと品質を継続的に比較・改善し、利用者が短期間で業務に使える回答を得て、本来のビジネス課題に集中できる状態を目指します。
