# あそぴてっくのGraphRAG導入ガイド

このリポジトリは、企業や組織に分散する文書、表、履歴、チケットなどの情報を、根拠をたどれる業務回答へ変えるためのGraphRAG導入ガイドです。

大量の情報から必要な事実だけを探すだけでなく、文書をまたぐ実体、関係、時系列、例外、出所を保ちながら、利用者が判断できるコンテキストへまとめることを扱います。目標は、利用者が技術方式の比較に時間を使うことではなく、短期間で業務に使える回答基盤を確かめ、本来のビジネス課題へ集中できる状態を作ることです。

## あそぴてっくの提供方針

あそぴてっくは、ユーザーのビジネス課題を起点に、情報圧縮とコンテキスト注入という原理から必要な技術特性を考えます。現在のコスト、品質、導入期間、再利用性を総合し、GraphRAGを現状の最尤解と判断して、RAG導入の標準テンプレートとして提案します。

案件では、GraphRAGテンプレートを対象業務へ適用する設計を行います。利用者のデータ、代表質問、判断基準、権限、更新条件、業務フローをテンプレートへ接続し、回答品質、根拠、費用、応答時間を実データで確認します。

## このリポジトリで確認できること

- 情報圧縮とコンテキスト注入を起点にした設計原則
- GraphRAGを標準テンプレートとして提案する判断と提供方法
- 対象データ、業務課題、権限、更新条件のアセスメント
- 回答品質、圧縮損失、来歴、費用、遅延の評価方法
- 業務ユースケースごとの適用・実証計画
- 技術的な主張、適用条件、未検証事項の根拠

このリポジトリを、あそぴてっくのGraphRAG導入方法に関する技術的な正本とします。LP、スライド、PDFなどの説明資料は、ここに記録した原則、適用条件、評価結果から作成します。
