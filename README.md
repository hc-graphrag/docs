# あそぴてっくのAIエージェント向けGraphRAG導入ガイド

このリポジトリでは、お客様がAIエージェントに行わせたい業務行動へ、必要なコンテキストを根拠付きで供給するためのGraphRAG導入支援をご案内します。

あそぴてっくのRAG導入支援では、GraphRAGを標準テンプレートとして導入し、エージェントが状況を認識し、計画し、判断し、ツールを実行し、結果を検証するためのコンテキスト供給基盤として構成します。

## ご提案の起点

最初に、お客様がエージェントに行わせたいユースケースと、得たい業務成果を伺います。次に、お客様のデータの内容、形式、粒度、由来、来歴、版、時点、権限、更新性が、そのユースケースを成立させる情報を備えているかを、技術者としてアセスメントします。

アセスメント結果に基づき、GraphRAGテンプレートのデータモデル、抽出、階層、検索経路、コンテキスト編成を対象業務へ対応付けます。テンプレートは再利用する実装の型であり、ユースケースとデータの適合判断およびテンプレートへの対応付けはasopitechが行います。

現在のコスト、品質、導入期間、再利用性を総合し、GraphRAGを現状の最尤解と技術者として判断しています。GraphRAGをRAG導入の標準テンプレートとしてご提案申し上げます。

## このリポジトリでご確認いただけること

- AIエージェントの行動へコンテキストを供給するRAGシステムモデル
- ユースケースとデータの適合性をasopitechが判断するアセスメント
- 情報圧縮、階層化、復元、コンテキスト注入の設計原則
- ユースケースとデータの形式・内容・由来・来歴を確認する適用アセスメント
- GraphRAGテンプレートの提供範囲と対象業務への適用方法
- 行動完了、根拠、データ適合性、費用、遅延の評価方法
- 代表行動シナリオによる実証計画
- 技術的な主張、適用条件、検証状況の根拠
