# あそぴてっくのAIエージェント向けGraphRAG導入ガイド

このリポジトリでは、お客様がAIエージェントに行わせたい業務行動へ、必要なコンテキストを根拠付きで供給するためのGraphRAG導入支援をご案内します。

RAGを検索回答システムとして限定せず、エージェントが状況を認識し、計画し、判断し、ツールを実行し、結果を検証する各段階へコンテキストを与えるシステムとして設計します。

## ご提案の起点

最初に確認するのは、お客様がエージェントに、RAGで与えるコンテキストを使って何を行わせたいかです。ユーザーが求める業務成果から、エージェントの行動、行動境界、完了条件、必要なコンテキストを定めます。

次に、そのユースケースと、お客様のデータの形式・内容・由来・来歴・版・時点・権限・更新性が対応するかを評価します。その対応を確認したうえで、情報圧縮、階層化、復元、コンテキスト注入の原理から適用方法を設計します。

現在のコスト、品質、導入期間、再利用性を総合し、GraphRAGを現状の最尤解と技術者として判断しています。GraphRAGをRAG導入の標準テンプレートとしてご提案申し上げます。

## このリポジトリでご確認いただけること

- AIエージェントの行動へコンテキストを供給するRAGシステムモデル
- ユーザー成果、エージェント行動、コンテキスト要件の対応
- 情報圧縮、階層化、復元、コンテキスト注入の設計原則
- ユースケースとデータの形式・内容・由来・来歴を確認する適用アセスメント
- GraphRAGテンプレートの提供範囲と対象業務への適用方法
- 行動完了、根拠、データ適合性、費用、遅延の評価方法
- 代表行動シナリオによる実証計画
- 技術的な主張、適用条件、検証状況の根拠
