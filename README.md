# あそぴてっくのGraphRAG導入ガイド

このリポジトリでは、企業や組織に分散する文書、表、履歴、チケットなどの情報を、根拠をたどれる業務回答へ変えるGraphRAG導入支援の方法をご説明します。

文書をまたぐ実体、関係、時系列、例外、出所を保ちながら、業務判断に必要なコンテキストを構成します。短期間で業務に使える回答基盤をご用意し、お客様が本来のビジネス課題へ集中できる状態を目指します。

## 提供方針

お客様のビジネス課題を起点に、情報圧縮とコンテキスト注入という原理から必要な技術特性を考えます。現在のコスト、品質、導入期間、再利用性を総合し、GraphRAGを現状の最尤解と判断して、RAG導入の標準テンプレートとしてご提案します。

案件では、お客様のデータ、代表質問、判断基準、権限、更新条件、業務フローを整理し、GraphRAGテンプレートを対象業務へ適用する方法を設計します。回答品質、根拠、費用、応答時間を実データで測定し、導入範囲と次の判断材料をご報告します。

## このリポジトリでご確認いただけること

- 取得からコンテキスト再構成までのRAGシステムモデル
- 情報圧縮、階層化、復元、コンテキスト注入の設計原則
- GraphRAGを標準テンプレートとしてご提案する理由と提供方法
- 対象データ、業務課題、権限、更新条件のアセスメント
- 回答品質、圧縮損失、来歴、費用、遅延の評価方法
- 業務ユースケースごとの適用・実証計画
- 技術的な主張、適用条件、検証状況の根拠

このリポジトリをGraphRAG導入方法に関する技術的な正本として管理します。LP、スライド、PDFなどの説明資料も、ここに記録した原則、適用条件、評価結果に基づいて作成します。

## GraphRAGの開発を先行して追う

GraphRAGの導入ガイドや評価資料は、どなたでもこのリポジトリで読めます。公開前の設計や試作から開発を追いたい方には、[GitHub Sponsors](https://github.com/sponsors/asopitech) に先行閲覧プランがあります。

- **Early Access**：設計ドラフト、実験の記録、試作から、GraphRAGの設計や検証がどのように進んでいるかを追えます。
- **Enterprise-focused Early Access**：セキュリティやシステム導入に関わる企業向け機能を、公開前の段階から追えます。

このリポジトリの公開資料のうち、`concepts/` と `design/` は両プラン向けのリポジトリにも同期し、`specs/` はEnterprise向けにのみ同期します。ルート直下のガイドなど、それ以外の資料はこのリポジトリで読めます。フォルダの違いは同期先を決めるもので、元の資料の公開範囲は変わりません。
