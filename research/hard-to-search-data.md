# 検索が難しい企業データ：仮説と検証方法

この資料は、企業データをRAGで利用するときに、検索品質へ影響するデータ上の特徴と検証方法を整理します。検索品質は、取得方式に加えて、取り込み、構造保持、識別子、版、権限、更新の設計によって変化します。

## 1. データ種別ごとの仮説

| データ | 品質へ影響する特徴 | 検証する処理 |
|---|---|---|
| スキャンPDF・FAX | OCR誤り、段組、脚注、ページ境界 | OCR、レイアウト保持、ページ参照 |
| 表・Excel | 行列、結合セル、単位、複数シート | 表構造抽出、見出し、セル位置 |
| 図面・CAD・写真 | 座標、記号、注記、部品との対応 | OCR、記号抽出、部品表との結合 |
| 略語・型番・旧称 | 表記揺れ、別名、同名異物 | 辞書、別名、共通ID、語彙検索 |
| 契約・規程 | 条項参照、定義、例外、改訂版 | 条項ID、参照関係、版、有効日 |
| 顧客の声・問い合わせ | 発言、要望、観測事実、担当者判断の混在 | 由来、対象製品、期間、分類 |
| 調査・提案資料 | 主張、根拠、推定、発行時点の混在 | 出典、主張と証拠の対応、更新版 |

## 2. 検証方法

1. 対象ユースケースで必要な情報を定義します。
2. 提供元の承認を得た小規模サンプルを、許可された処理環境へ用意します。
3. 人手で期待する検索結果と根拠位置を作成します。
4. 現行検索、キーワード検索、ベクトル検索を基準として測定します。
5. 各加工物の保存先と権限を固定し、構造保持、辞書、識別子、階層化などの処理を一つずつ追加します。
6. 取得品質、原情報への復帰、費用、応答時間の変化を記録します。

## 3. 記録する結果

| 記録項目 | 内容 |
|---|---|
| 対象データ | 種別、件数、版、期間、権限 |
| 利用条件 | 配置先、提供元の承認、加工主体、派生データの保存・削除条件 |
| 正解データ | 期待する証拠と原情報の位置 |
| 適用処理 | 取り込み、抽出、検索、再順位付け |
| 品質 | Recall、順位、構造保持、参照復帰 |
| 運用条件 | 更新、削除、権限反映 |
| コスト | 前処理、索引、検索、再評価 |

## 4. アセスメントへの反映

検証で確認したデータ上の特徴と有効な処理を、[ユースケース・データ適合アセスメント](../enterprise-data-assessment.md)の根拠として記録します。効果の大きさと適用条件は、対象ユースケースと実データごとに示します。
