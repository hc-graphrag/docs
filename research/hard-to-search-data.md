# 検索しづらい企業データ: 仮説と検証計画

状態: 初期調査フレームです。顧客データの頻度や効果を確認した調査結果ではありません。

| データ | 難しさの仮説 | 検証候補 |
|---|---|---|
| スキャンPDF・FAX | OCR誤り、段組や脚注の崩れ | OCR、レイアウト保持、ページ出典 |
| 表・Excel | 行列、結合セル、単位、複数シート | 表構造抽出、見出し連結、セル位置 |
| 図面・CAD・写真 | 意味がテキストにない、注記が小さい | OCR/記号抽出、部品表との結合 |
| 略語・型番・旧称 | 文書ごとの表記揺れ | 辞書、別名、ID正規化、キーワード併用 |
| 時系列保全記録 | 古い状態が現在の事実に見える | 有効期間、設備ID、時間フィルタ |
| 契約・規程 | 否定、例外、条項参照、改訂版 | 条項ID、版・有効日、根拠位置 |
| 医療記録 | 機密、略記、時系列、厳格な権限 | 仮名化、最小権限、時系列、棄権 |

## 実査

データ種類・所有部門・形式・更新率を台帳化し、許可済みの小サンプルと人手の質問・根拠を作成。現行検索、キーワード、ベクトル、ハイブリッドを比較し、OCR・構造化・辞書を一つずつ追加して寄与を測ります。誤検索の影響と前処理・運用コストも記録します。

提案: 問題を検索アルゴリズムだけに限定せず、取り込み、権限、更新、メタデータ、出典リンクを含むパイプラインとして扱います。

未検証: 特定業界でGraphRAGが他方式を上回るという主張、効果量、導入期間、削減率。検証前に数値訴求しません。
